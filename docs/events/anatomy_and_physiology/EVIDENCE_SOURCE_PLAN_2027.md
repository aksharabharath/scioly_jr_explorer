**Source-planning and evidence-mapping only.** This is not a question bank, not an evidence matrix of extracted facts, and not permission to mark future items verified.

Do not write questions from this file. Do not treat general biology as official Science Olympiad content. Do not invent classification grades, origins, treatments, or imaging findings.

## 0. Four kinds of evidence

Keep these separate. A row can need more than one.

| Kind | Answers | Typical source |
|---|---|---|
| **Official scope evidence** | Is this topic in the 2027 event? Closed list? `limited to` / `e.g.` / `as listed`? | Tier 1 — `RULES_2027.md` |
| **Factual biology evidence** | What is the origin, mechanism, sign, treatment, or grade? | Tier 2–3 medical/anatomy references |
| **Question-writing evidence** | Can this fact become a fair 4-choice item at elementary/middle level? | Same references + blueprint duplicate-control |
| **Visual / image evidence** | Can the student label or interpret a figure/radiograph? | Licensed or original figures; OpenStax CC-BY; radiology libraries with per-asset licenses |

The rules **require** many facts they **do not provide**. That is `SOURCE NEEDED` until a Tier 2–3 source is **recorded** in a later evidence matrix — even if this plan already **names** a recommended book or agency page.

**Status meanings in this file**

| Status | Meaning |
|---|---|
| `RULES ONLY` | The rules fully supply the testable content (list membership, named groups, scope limits) |
| `READY FOR AUTHORING` | Enough evidence exists **now** to write a science item without waiting (almost only `RULES ONLY` list-literacy) |
| `SOURCE FOUND` | A **specific** recommended source is identified that is expected to cover the fact — **not yet extracted**; not verified |
| `SOURCE NEEDED` | No adequate specific source is identified, or coverage is uncertain until a page is recorded |
| `IMAGE SOURCE NEEDED` | A visual asset is required (or required for that blueprint slot) and is not in the repo |
| `NEEDS HUMAN REVIEW` | Naming conflict, classification-scheme choice, or source disagreement — do not guess |

Do **not** use `VERIFIED` in this document.

## 1. Source hierarchy

### Tier 1 — Official Science Olympiad

Use for scope, closed lists, named conditions, the 28-muscle list, mechanics, and qualifiers (`limited to`, `as listed`, `e.g.`).

- `docs/events/anatomy_and_physiology/RULES_2027.md` (in-repo primary)
- Later: official clarifications/corrections if Science Olympiad publishes them

**Do not** use Tier 1 as a medical textbook. It does not define osteons, PTH mechanisms, Salter-Harris grades, or muscle origins.

### Tier 2 — High-authority medical / anatomical references

Government agencies, major academic medical centers, NCBI Bookshelf professional reviews, established anatomy textbooks.

Use for definitions, pathology, treatment/prevention, anatomy, physiology, mechanisms, imaging characteristics.

### Tier 3 — Academic educational sources

University A&P textbooks written for undergraduates, when Tier 2 is too clinical or too thin for classroom wording.

**Primary planned textbook:** OpenStax *Anatomy and Physiology 2e* (Rice University / OpenStax). CC-BY; chapters 5–11 match the three event systems.

### Tier 4 — Secondary educational sources

Use only if Tiers 2–3 fail, and label them secondary. **Do not** use random blogs, SEO health sites, unsourced study sites, or AI-generated pages as evidence.

## 3. Source-conflict rules

If two authoritative sources disagree:

1. Record **both** quotations and locations.
2. Do **not** silently pick one.
3. State the exact conflict (term, grade count, attachment, treatment).
4. Prefer the source that matches event educational level **only after** documenting the conflict.
5. If still ambiguous → `NEEDS HUMAN REVIEW`.

Never guess numerical values, classification grades, official muscle attachments, or disease-distinction criteria.

Known conflict to watch (do not resolve here):

| Topic | Conflict |
|---|---|
| Muscle list title | Rules body: “2025 National Major Skeletal Muscles List”; appended list: “2027 ESO Major Skeletal Muscles List” (28 names). Use the **28 appended names**; do not import another year’s list. |
| `Extensor carpi radialis` | SO prints one name; T3-OS typically treats **longus** and **brevis** separately. |
| `Iliopsoas` | SO prints one name; many texts describe iliacus + psoas major. |
| Burns classification | Rules require “burns and their classification” but **do not name** the scheme (degrees vs partial/full thickness vs TBSA). Record whichever scheme the chosen source uses; do not invent one. |
| Salter-Harris | Some reviews mention types beyond I–V. Extract **only** the system the chosen article attributes to Salter and Harris (1963) unless a later official SO clarification names extras. |
| OA vs RA | Independent disease pages are not a comparison. Need sources that **contrast** them, or two pages plus an explicit documented contrast table. |
