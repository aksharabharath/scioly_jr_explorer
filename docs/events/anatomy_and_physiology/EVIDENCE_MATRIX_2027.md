## 0. Status vocabulary

Use only these statuses:

| Status | Meaning |
|---|---|
| `RULES-SCOPE` | Topic/skill required by the 2027 rules; **no** biological answer in the rules |
| `SOURCE-VERIFIED` | Claim is supported by an inspected approved source + short quotation |
| `IMAGE-SOURCE-VERIFIED` | A specific visual diagnostic is supported by an acceptable licensed image **in hand** |
| `SOURCE-NEEDED` | Required fact not yet established from an inspected source |
| `HUMAN-REVIEW` | Evidence exists but naming, scheme choice, conflict, or product use needs a human |
| `OUT-OF-SCOPE` | Do not author |

**This pass: `IMAGE-SOURCE-VERIFIED` = 0.** No radiographs or diagrams were added to the repo. OpenStax figures exist on the web but were not ingested as licensed app assets. Do not mark a visual item verified because a textbook says a structure exists.
