# Entomology 2027 — ESO Entomology List

**Canonical constraint for Jr. Explorer Entomology questions.**

**Authority:** scientific names, ranks, grouping, common-name strings, and asterisks below are copied from `docs/events/entomology/RULES_2027_OFFICIAL.md` (ESO Entomology LIST). That file is the project’s authoritative 2027 rules source.

**Organizational:** indentation and rank labels (Class / Subclass / Order / Family) are added for maintainability. They do not add taxa.

Do **not** “correct” official spelling, punctuation, or capitalization for style.
