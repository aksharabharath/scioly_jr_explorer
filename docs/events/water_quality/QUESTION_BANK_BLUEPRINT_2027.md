## 3. Slot types that **are** in MVP (still unwritten)

### 3.1 Indicator / class / labels (~10–12)

Examples of **allowed** operations (not stems):

- Match an official class **title** to its number.
- Given a listed name, choose its official class (application of the table).
- Distinction: which of four listed names is **not** Class 1.
- Simple two-couplet **name-only** key using official class titles (same pattern as Entomology list keys).
- Recognize that Freshwater Ecology is one of the three official topics, or that a `such as` phrase is a **named example** (not a definition of the water cycle).

**Not in MVP:** why mayflies indicate clean water; food webs; treatment plant steps; sedimentation mechanisms (`SN1`, `SN5`, `SN15`, `SN16`).

### 3.2 Macroinvertebrate list (~12–15)

- Place printed names in classes (S3).
- Distinguish Class 5 air-breathing **column** from Class 4 names without inventing physiology (`HR6`: do not equate “air breathing” biology with Class 5).
- Use exact strings: **Damsefly**, **Predacious Diving Beetle**, **Deer/Horse Fly**, **Leeches**.

**Not in MVP:** photo ID (`IM1`); feeding (`SN2`); scientific names (`SN14`); immatures.

### 3.3 Nuisance (~6–8)

- Which names are on the plant list vs the animal list.
- Which of four names is a listed nuisance organism vs a table macro (when the distractor is actually on the other official list).
- Exact **Crayfish/Crawdads** as one official string (`HR4`: do not split).

**Not in MVP:** impacts, vectors, photos (`IM2`), feeding (`SN4`).

### 3.4 Monitoring (~8–10)

- Which of four names is one of the eight official parameters (S6).
- Qualitative: DO = dissolved O₂ available to aquatic life (`V-U1`).
- Qualitative: colder water can hold more DO than warmer water (`V-U2`) — **text**, no graph (`IM4`).
- Temperature affects what can live in a water body (`V-U3`).
- Nitrate is a nitrogen nutrient; excess can overstimulate plants/algae (`V-U4`).
- BOD = oxygen used by microbes breaking down organic matter; organic-pollution index (`V-U7`).
- Salinity/saline water involves dissolved salts (`V-U6`) — **no** ppm bands.

**Not in MVP:** pH or turbidity definitions (`SN6`, `SN7`); phosphate = phosphorus unless HR7 is resolved; procedures (`SN8`); sample-data stems (`IM5`); mg/L or ppm cutoffs (`SN12`).
