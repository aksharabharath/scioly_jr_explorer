## 0. How to read this inventory

### Authority

Only statements in `RULES_2027.md` are treated as official for this pass.

If a field is absent from that file, it is recorded as **`NOT STATED`**. Gaps are not filled from general knowledge.

### Evidence labels (scope vs fact)

| Label | Meaning |
|---|---|
| `RULES-SCOPE` | The rules say this topic, skill, list, or format **can or will be tested**. Does **not** by itself verify a scientific answer. |
| `SOURCE-VERIFIED` | The answer text is fully supplied by the rules file (usually a closed list row or an exact logistics sentence). |
| `SOURCE-NEEDED` | In scope, but the rules do not supply the factual detail needed to verify a question. |
| `IMAGE-SOURCE-NEEDED` | Visual or data-asset interpretation is in scope (or implied by identification), but this repo has no usable asset. |
| `HUMAN-REVIEW` | Official wording is ambiguous, misspelled, or combinable in more than one reasonable way. |

A row may carry both a **scope** label and a **fact** label.

### Open vs closed wording

| Rules wording | How this inventory treats it |
|---|---|
| Named table / “listed below” | Closed for the printed names. Do not add siblings. |
| **areas such as** | Open-ended topic examples. Named items are in scope as names. Do **not** treat the list as complete, and do **not** invent missing topics. |
| **may include** | Optional contest content. In scope. Not a guarantee that every contest includes it. |
| **will** | Stated requirement (format, question count, materials ban, scoring). |
